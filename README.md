# Projet Temps réel
Réaliser un robot suiveur de ligne en temps réel avec l'Adeept Motor HAT V2 et le Raspberry PI. 
Générer une fonction en C pour la détection des capteurs IR entre la couleur blanche ou noire en utilisant la bibliothèque WiringPi.
Concevoir une fonction temps réel collectant les données des capteurs comme des tâches périodiques avec une haute priorité.
